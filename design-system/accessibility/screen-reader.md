# IDS Screen Reader

Screen-reader output should communicate the same hierarchy and state that sighted users receive.

## Required information

- Name: what the control is.
- Role: what kind of control it is.
- State: selected, expanded, checked, disabled, loading, invalid, etc.
- Value: the current value when applicable.
- Relationship: label, description, error, and supporting content where applicable.

## Rules

Do not announce decorative icons. Do not duplicate visible text unnecessarily. State changes must be perceivable without relying on color, animation, or position alone.
