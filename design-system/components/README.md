# IDS Components

This directory contains the implementation-neutral contracts for the Itunda Design System.

Start with [core-primitives.md](./core-primitives.md).

The contract is the source of meaning. Web, Android, and iOS implementations are reference implementations of that contract and must not introduce product-specific variants into the public component API.

## Layers

1. Foundations — primitive values.
2. Semantic tokens — meaning and theme.
3. Components — reusable UI contracts.
4. Patterns — task-level compositions.
5. Products — Itunda client, Business, Developers, and Tech experiences.

Local product needs should remain local until repeated use demonstrates that they deserve promotion into IDS.
