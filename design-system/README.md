# Itunda Design System

Standalone documentation and interactive showcase for IDS v2.

This site is intentionally independent from the Itunda Developers documentation. The canonical design-system source remains in the Itunda repository under client/design-system and the native platform implementations.

## Sections

- Foundations
- Components
- Product patterns
- Platform parity
- Accessibility
- Tokens
- ItundaFace
- Interactive sandbox

The site is designed to be deployed independently from the monorepo as its own Cloudflare Pages project.
