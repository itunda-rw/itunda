# Android launcher icon sources

Per product direction: launcher = white tile + knot in itunda purple (#8F89FF), like Toss.
On a purple tile the knot is black; in light/dark UI the knot is purple. The canonical v3
archive under `packages/brand-assets` is left untouched (it is hash-pinned); these three SVGs
are the Android-only sources that `scripts/sync-native-brand-assets.sh`, the brand workflow and
`scripts/verify-native-brand-assets.py` render from.
