# Itunda Design System

IDS is the shared visual and interaction language for Itunda Web, Android and iOS.

The developer showcase at `/design/` is the public documentation surface. The canonical source remains the Itunda repository.

## Identity

- Primary brand: `#1F78FF`
- Accent: `#1769E0`
- Surface tint: `#EAF3FF`

## Principles

Clarity, consistency, accessibility, native platform behavior, and restrained visual hierarchy.
