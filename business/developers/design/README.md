# Itunda Design System (IDS 3.0)

IDS is the shared visual and interaction language for Itunda Web, Android and iOS. IDS 3.0 is the component contract layer: foundations → anatomy → variants → states → edge cases → accessibility → platform behavior.

The developer showcase at `/design/` is the public documentation surface. The standalone `design-system/` site is the deeper documentation surface. The canonical source remains the Itunda repository.

## Identity

- Primary brand: `#1F78FF`
- Accent: `#1769E0`
- Surface tint: `#EAF3FF`

## IDS 3.0 contract

Every reusable component must define:

- anatomy and structural hierarchy
- variants and sizes
- default, pressed, focus, disabled, loading, empty, error and success states where applicable
- long content and large-text behavior
- light and dark semantic tokens
- keyboard, screen-reader and touch-target behavior
- Web, Android and iOS implementation notes
- content guidance and do/don't examples

## Principles

Clarity, consistency, accessibility, native platform behavior, and restrained visual hierarchy.
