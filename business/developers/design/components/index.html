Actions

Primary, secondary, weak and text actions. One dominant action should remain visually obvious.

Button

Anatomy: label · optional leading icon · loading indicator

States: default · hover · pressed · focus-visible · disabled · busy. Accessibility: native button semantics; never communicate state by color alone.

Action group

Use when two or more actions belong to one decision.

Responsive rule: wrap before shrinking labels into ambiguous icons.
