Payments are created server-side with an API key and an idempotency key, then completed through a hosted checkout.

PAY ITUNDA · API

Create a payment

POST /api/v1/pay/payments
X-Api-Key: sk_test_...
Idempotency-Key: <unique-request-key>

{ "amount": 1000, "currency": "RWF", "reference": "order_123" }
The current repository uses sk_test_ credentials. Keep secrets on your server and treat this as a test/sandbox surface unless your environment explicitly indicates otherwise.
