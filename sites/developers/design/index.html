ITUNDA DESIGN SYSTEM

Clear by design.
Quiet by default.

One visual language for Itunda products: strong hierarchy, restrained color, predictable spacing and components that explain their state without visual noise.

01 · Principles

Let content create the hierarchy.

Color and decoration are supporting tools. Structure comes first, so users can scan, understand and act quickly.

One core messageMake the purpose obvious before presenting controls.
Indigo is an accentReserve #7472F4 for brand, primary actions and selected states.
Neutrals carry the UIUse surfaces, type and separators to create most of the visual structure.
02 · Foundations

Small tokens. Consistent results.

The same decisions repeat across web, Android and iOS without turning every screen into a collection of colored cards.
